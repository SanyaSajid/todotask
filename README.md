# To-Do Task App

A simple task manager built with HTML, CSS and vanilla JavaScript. Tasks are saved in the browser, so they are still there after a refresh.

## Features
- Add a new task from the input box
- Edit an existing task
- Mark a task as done (moves to a separate "done" list)
- Delete tasks
- Data persists using `localStorage`
- Custom UI with SVG icons and Inter font

## Tech Stack
HTML5, CSS3, JavaScript (DOM manipulation, localStorage)

## Project Structure
```
todotask/
├── index.html   # layout and task container
├── style.css    # styling
└── main.js      # add / edit / done / delete logic and localStorage
```

## Run Locally
```bash
git clone https://github.com/SanyaSajid/todotask.git
cd todotask
# open index.html in your browser
```
